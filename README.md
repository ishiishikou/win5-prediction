# win5-prediction

AIでJRA WIN5を予想し、**事前予想を固定したうえで長期的な再現性・的中率・収支を検証する**公開実験リポジトリです。

目的は「必勝法」を主張することではなく、予算制約のあるWIN5予想で、AIがどの程度の予測優位性を持てるかを監査可能な形で測ることです。

## 実験ルール

- 標準予算は **3,000円 / 開催（1点100円、最大30点）**。
- 最終予想は最初のWIN5対象レースの締切前にコミットする。
- 締切後は `predictions/` の内容を修正しない。誤記が見つかった場合も履歴を残し、結果側で注記する。
- 結果確定後に `results/` を追加する。
- JRA公式を一次情報として、対象レース・取消/変更・結果・払戻金を確認する。
- 実購入と仮想購入は区別して記録する。
- 結果を知った後の後知恵で予想ロジックを書き換えない。改善は次開催から適用する。

## ディレクトリ

- `prompts/` — 予想に使う再利用プロンプト
- `docs/` — 検証方法、評価指標、運用ルール
- `predictions/YYYY/` — 締切前の最終予想
- `results/YYYY/` — 結果・振り返り
- `data/summary.csv` — 開催ごとの集計

## 評価指標

主に次を追跡します。

- 投資額
- 払戻額
- 純損益
- 回収率 = 払戻額 / 投資額
- 純ROI = (払戻額 - 投資額) / 投資額
- WIN5的中率
- 5レース中、選択集合に勝ち馬を含められたレース数
- 最大連敗・最大ドローダウン
- 事前登録済み開催だけの監査可能な成績

JRAのWIN5設定払戻率は現在70%です。長期的に市場平均を上回れるかを一つの基準にします。
https://www.jra.go.jp/kouza/win5/carry/
